# Exercice Javascript 01

## Objectifs 

Appréhender le fonctionnement du Javascript et de sa mise en lien avec un site web classique

## Sujet 

Via l'utilisation d'un site web vide ainsi que d'un fichier de script Javascript, réaliser un ensemble de questions / réponses pour un utilisateur lambda.

Le script aura pour but de demander à l'utilisateur son nom, son prénom, son âge ainsi que son animal préféré. Il lui sera affiché ensuite un message personnalisé du type : 

```text
Bonjour John DOE ! 
* Vous avez 23 ans
* Votre animal de compagnie est un chat
```
